# IdeoSphere Community

Welcome to the IdeoSphere Community project ! Feel free to join our community on [Discord](https://discord.gg/VY4xtKeZWV).

## Overview

IdeoSphere community is designed to facilitate collaboration and idea sharing among users. It includes a variety of features and components that enhance user interaction and content management. More [ideosphere.social](https://ideosphere.social/). Or check the current [standalone demo](https://demo-municipal.ideosphere.social/).

## Project Structure

- **production/**: Contains the source code and resources for the production-ready version of the application.
- **README.md**: This file provides an overview and instructions for the project.
- **LICENSE**: Licensing information for the project.

## Setup Instructions

1. **Clone the repository**:
   ```
   git clone https://github.com/yourusername/IdeoSphere-Community.git
   cd IdeoSphere-Community
   ```

2. **Install dependencies**:
   Go to the `production` directory and run:
   ```
   npm install
   ```

3. **Run the application**:
   ```
   cd production
   npm run dev
   ```
   Open `test-tenant.localhost:3000` so the backend can resolve the tenant (see `RECAP_FRONTEND.md`).
