## 📝 Comment Contribuer à la Documentation

### Créer un nouveau document

1. Choisir le bon emplacement (racine, /docs/, dossier spécialisé)
2. Utiliser un nom descriptif en UPPERCASE pour docs importantes
3. Inclure la date de création
4. Ajouter une section "Dernière mise à jour"
5. Référencer depuis ce fichier index

### Mettre à jour un document

1. Mettre à jour la date "Dernière mise à jour"
2. Ajouter les changements au /CHANGELOG.md si pertinent
3. Mettre à jour l'index si changement de priorité/statut

### Obsolescence

1. Marquer comme ⚠️ OBSOLÈTE dans le titre
2. Expliquer pourquoi et quel document le remplace
3. Déplacer dans la section "Documents Obsolètes" de cet index
4. Garder pour référence historique
